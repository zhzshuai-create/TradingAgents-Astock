## 四、偏离与坑

1. **后端日志走控制台**：`stack_launch` 直接 Popen 继承输出，不写 `%TEMP%\astock-stack\backend-next.log`。真实 runner 用控制台 `INFO astock.backend: worker real` 确认，无 fake graph 警告。要文件日志时再统一到 `stack_mode.log_path()`。
2. **`.bat` 里不要写非 ASCII**：第一次改 `run_all.bat` 写了 UTF-8 中文 REM，cmd 按 GBK 解析报「此时不应有…」；注释改 ASCII 后正常。原文件虽是 UTF-8+LF，但中文行在改动后更容易触发解析错位。
3. **Ctrl+C 未做真机按键验证**：自动化里用 `taskkill /T` 模拟关闭控制台；`finally` 回收三个子进程的代码路径已有，但没有在真实按键下走一遍。
4. **备份口径**：P6-07 交接卡里的 240 是真实根含 cache/logs 的总数；`backup --live` 只收 150 个白名单文件，manifest 校验通过。
5. **`--build-ui` 与前置检查**：缺 dist 时 `--build-ui` 只要求 vite 工具链存在，构建后再起预览；不加该参数才提示 `npm run build`。
