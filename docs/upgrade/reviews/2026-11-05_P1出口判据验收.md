### 2.1 20 个并发相同创建只执行一次

ID-05 连跑 10 轮，每轮 20 个线程、20 把不同幂等键提交同一票同日同配置：每轮只产生 1 个任务、1 个 201，20 把键都绑到这一行。

FT-03 单独再跑 20 线程，并继续执行到 succeeded：库内只有 1 个任务，12 个阶段目录各只有 `attempt-1.md`，广播事件 40 条，阶段行 12 条。

命令与结果：

```
.venv/Scripts/python.exe -m pytest tests/backend/test_create_idempotency.py::test_id05_twenty_concurrent_creates_make_one_job tests/backend/test_kernel_perf_faults.py::test_ft03_twenty_concurrent_creates_run_once -q
2 passed in 4.36s
```

兜底靠 `jobs` 表的部分唯一索引 `uniq_active_fingerprint`，不是应用层先查后插。提交 P1-04 `4fde141`，测试补强 P1-13 `bddd76b`。

### 2.2 API 重启后重连并补发遗漏事件

GF-20 覆盖同进程内的游标补发。FT-01 补上进程级证据：任务跑到终态后，在同一个库上新建引擎、JobService、EventStream 与 FastAPI 应用，等价于 API 进程重启。

新进程先带 `Last-Event-ID: 0` 读快照与前 3 条广播事件，再用游标 3 重连。第二段响应先给一条快照（序号 40），随后按 `seq 4..40` 连续补发，事件类型与库内广播行逐条相等，没有重复也没有空洞。

命令与结果：

```
.venv/Scripts/python.exe -m pytest tests/backend/test_sse.py::test_gf20_reconnect_replays_only_after_the_cursor tests/backend/test_kernel_perf_faults.py::test_ft01_restarted_app_replays_from_last_event_id -q
2 passed in 1.48s
```

提交 P1-11 `eef8b47`，测试补强 P1-13 `bddd76b`。

### 2.3 Worker 崩溃不自动重跑

SM-13 让持有租约的任务在租约失效后进入对账，四个非终态状态全部转 interrupted，并写 `status_changed(reason=reconcile)`。

CB-02 覆盖 B2：没有产物的 running 行转 interrupted，不重跑。FT-02 连续做两次重启对账：第二次启动不认领、不改状态、不改断点、不新增事件、不新增阶段行、不写报告行与报告文件，磁盘产物逐字节不变。

崩溃原因写在对账事件的 `detail`：`lease_expired`、`unregistered_stage_output`、`unregistered_report`，备注写 `reconcile_note`（seq 为 NULL，不进事件流）。对账只写状态，不跑图、不调模型。

命令与结果：

```
.venv/Scripts/python.exe -m pytest tests/backend/test_crash_recovery.py tests/backend/test_kernel_perf_faults.py::test_ft02_second_restart_keeps_interrupted_and_adds_nothing -q
11 passed in 3.60s
```

提交 P1-10 `3576ed0`，测试补强 P1-13 `bddd76b`。

### 2.4 配置串行隔离（有条件通过）

数据层已验：FT-06 建两个配置不同的任务，`config_hash` 不同；任务 A 执行期间，A、B 的 `config_snapshot` 都保持原值，B 仍是 queued，阶段全 pending，全局租约不能被第二个 Worker 接管；A 完成后 B 再执行，两任务各自的 12 个阶段目录、`attempt-1.md` 与 `report_path` 前缀互不越界。

CFG 系列另覆盖配置规范化、哈希稳定性、未知键与非法值错误码、快照只读。合计：


未验部分是运行期：`AnalysisRequest` 只有 ticker 与日期，没有配置字段；P1 的默认执行器是假图，不读取任何配置。两个任务同时运行时是否共享配置对象，P1 没有代码路径可测。
