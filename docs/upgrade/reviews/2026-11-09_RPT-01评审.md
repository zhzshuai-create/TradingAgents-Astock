**存取。** [`ReportStore.write_chart_snapshot`](file:///C:/Users/zhzsh/TradingAgents-astock/backend/app/services/report_store.py#L136) 与 `report.json` 同款 `tmp` + `os.replace`；[`read_chart_snapshot`](file:///C:/Users/zhzsh/TradingAgents-astock/backend/app/services/report_store.py#L154) 只接受 `schema_version=chart-snapshot-v1`、`ticker`、`blocks` 三件齐全的文档，损坏或缺件返回 `None`。

**终态事务。** [`finish_success`](file:///C:/Users/zhzsh/TradingAgents-astock/backend/app/services/job_service.py#L936) 新增关键字参数 `chart_snapshot_status=None`。为 `None` 时完全保持现状；非 `None` 时校验枚举、非法值按 `none`，然后浅拷贝报告并覆盖 `meta`，不改调用方对象。数据库列、CHECK 约束、`finalize_report`、`report_ready` 载荷都没动。

**接线与开关。** [`build_chart_snapshotter`](file:///C:/Users/zhzsh/TradingAgents-astock/scripts/run_backend.py#L132) 默认返回真实实现，`TA_CHART_SNAPSHOT=0` 返回 `None`；`run_backend` 现在把同一份 `DefaultMarketProviders` 与 `MarketCache` 同时给 API 和快照器，命中缓存的概率与股票页一致。`e2e/e2e_p6.py` 的隔离环境显式写 `TA_CHART_SNAPSHOT=0`，离线 e2e 不会走到供应商超时。

**前端。** [`CHART_SNAPSHOT_LABELS`](file:///C:/Users/zhzsh/TradingAgents-astock/frontend/src/features/reports/format.ts#L36) 三个中文标签，[`ReportMeta`](file:///C:/Users/zhzsh/TradingAgents-astock/frontend/src/features/reports/ReportMeta.tsx#L40) 在「数据质量」下方加一行只读 `图表快照`，`data-testid="meta-chart-snapshot"`。列表、导出、`api/types.ts` 未改。
