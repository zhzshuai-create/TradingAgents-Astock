## 五、残留事项

- R1（跟进而非本票修复）：`DefaultMarketProviders.sector_blocks` 请求 `https://finance.pae.baidu.com/api/getrelatedblock` 时，百度对 python-requests 的 TLS 指纹返回 HTTP 403 风险控制（响应体 `Result.code=403`、`isCaptchaEnabled=true`）。同一 URL 与请求头用 curl 返回 200；`tradingagents/dataflows/a_stock/signals.py` 的同接口注释已记录同一风控。失败块不入缓存，处于 partial 的快照每次请求都会重试它，因此 live 暖 p95 达 3841 ms。影响：`sector_blocks` 长期缺块，快照退化为逐请求重试。建议另开票（负缓存/退避，或换能过风控的客户端）后再跑一次 `--live`；P4-12 只记录，不改产品行为。
- C9（已知瑕疵）：市场文案落在 `frontend/src/features/market/copy.ts`，与 `api-v1.md` 3.0 指向的 `semantic-dictionary.md` 不一致；契约不改，P5 统一收口。

- 性能真实时延只在有网络且供应商可用时可信；本机 live 数字只代表本机网络与供应商风控状态，不能外推。
