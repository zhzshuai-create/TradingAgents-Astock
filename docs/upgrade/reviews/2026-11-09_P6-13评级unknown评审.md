## 二、根因链

1. MiMo 的 `with_structured_output` 返回 `None`（没有 tool call），`render_pm_decision(None)` 抛 `'NoneType' object has no attribute 'rating'`。
2. `invoke_structured_or_freetext` 捕获异常，改走 `plain_llm.invoke(prompt)`，把原文直接作为 `final_trade_decision`。
3. PM prompt 只列了五档评级的含义，没有规定输出标签；模型写成中文标题和表格。
4. 后端按契约只认 `**Rating**: X`，解析失败即 `unknown`。

不能靠放宽解析器解决：[report-schema-v1.md:66](file:///C:/Users/zhzsh/TradingAgents-astock/docs/upgrade/contracts/report-schema-v1.md#L66) 明确「不做关键词猜测」，且该正文同时出现 Overweight、SELL、Underweight 多处评级——`signal_legacy=Buy` 就是猜错的实例。改解析属于「修改字段含义」，按 FREEZE-v1 要升 v1.1。
