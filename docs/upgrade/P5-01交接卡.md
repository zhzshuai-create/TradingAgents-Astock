## 五、口径

### 5.1 存储

```ts
type Density = "comfortable" | "compact";
type RefreshProfile = "standard" | "relaxed" | "manual";
type ExportProfile = "pdf" | "markdown";

interface LauncherDefaults {
  llm_profile?: string;
  parallel_analysts?: boolean;
}

interface Preferences {
  density: Density;
  refresh: RefreshProfile;
  export: ExportProfile;
  launcher: LauncherDefaults;
}
```

- 键：`astock.prefs.v1`；值为 JSON 对象。
- 默认：`comfortable` / `standard` / `pdf` / `{}`。
- 校验：只接受白名单枚举；`launcher` 只接受字符串或布尔；未知键丢弃；整体非法回默认。
- 读取：`localStorage.getItem`、`JSON.parse` 任一步抛异常都回默认，不把异常抛给组件。
- 写入：`JSON.stringify` 后 `setItem`；`QuotaExceededError` 或禁用存储时静默失败，内存状态仍生效。
- 订阅：模块级 `Set<() => void>`；`setPreferences(patch)` 合并、写入并通知；监听 `window` 的 `storage` 事件处理跨标签页变化；`usePreferences()` 用 `useSyncExternalStore`，服务端快照返回默认值。
- 禁止字段：`api_key`、`base_url`、`journal_url`、`data_dir`、任何环境变量。P5-03 会断言 localStorage 只有 `astock.prefs.v1` 与 `astock.theme`。

### 5.2 密度令牌

`tokens.css`：

```css
:root {
  --row-height: 44px;
  --row-padding-y: 10px;
}

:root[data-density="compact"] {
  --row-height: 36px;
  --row-padding-y: 6px;
}

@media (max-width: 767px) {
  :root,
  :root[data-density="compact"] {
    --row-height: 44px;
    --row-padding-y: 10px;
  }
}
```

- 只替换行高与行内边距；字号、颜色、列宽不动。
- 四份 CSS Module 的表格行/列表行使用 `height: var(--row-height)`（非表格列表可用 `min-height`）、`padding-block: var(--row-padding-y)`；不得把 `--row-height` 用在按钮或导航项上。
- 触控目标仍由各组件自己的 `min-height: 44px` 保证；密度令牌不降低移动端触控。

### 5.3 根属性

`AppShell` 在挂载与偏好变化时：

```ts
document.documentElement.dataset.density = preferences.density;
```

- 首帧用同步读取的初始值，避免先亮后跳。
- 卸载不移除属性（保持最后一次选择），与 `useTheme` 的根属性行为一致。
- 不读 `prefers-*` 推断密度；密度只有用户显式选择。
