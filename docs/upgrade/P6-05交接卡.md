## 六、已知坑

1. Playwright 只在系统 Python 3.13；用 `.venv` 跑会 `ModuleNotFoundError`。
2. vite preview 默认 4173；必须 `free_port()` + `--strictPort`，否则端口漂移会让结果不可复现。
3. 构建产物过期会让数字失真；每次测量前重新 build，并确认 manifest 时间戳。
4. 本机抖动大：p75 + 20 样本是最低要求，不要用单次值下结论。
5. LCP 只对首屏有意义；刷新交互会重置 LCP，首屏 LCP 与交互 INP 分开统计。
6. INP 不会因为 `page.goto` 出现；必须有真实点击 / 键盘 / 路由变化，交互后等一帧再读。
7. CLS 的 `layout-shift` 要过滤 `hadRecentInput`，否则点击造成的位移会把 CLS 抬高。
8. 并行阶段 `started_at == finished_at` 是后端现象，与本票无关；测量统一用页面内 `performance.now()`，不做跨进程时钟对齐。
9. Windows 控制台 GBK：输出中文前设 `PYTHONIOENCODING=utf-8`。
10. 不新增运行时依赖；Playwright 是测量工具，不写进 `frontend/package.json` 的 dependencies。
11. 端口互锁与 `run_all.bat` 属 P6-06；本票不要动。
12. 判分函数要能注入样本，否则 PF-03 只能靠真机抖动碰运气。

## 附录 A：`perf_core.py` 骨架

骨架只锁结构与判定，选择器与夹具按实际 DOM 补；不要把它当最终实现。

```python
"""P6-05 性能门禁：LCP / CLS / INP 六条线。"""
from __future__ import annotations

import argparse
import json
import math
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
TARGET = {"lcp_ms": 2000, "cls": 0.05, "inp_ms": 150}
REGRESSION = {"lcp_ms": 2500, "cls": 0.1, "inp_ms": 200}
VIEWPORTS = {
    "mobile": {"width": 390, "height": 844},
    "desktop": {"width": 1440, "height": 900},
}
INTERACTIONS = ["manual_refresh", "market_to_stock", "list_filter"]


def p75(values: list[float]) -> float:
    ordered = sorted(values)
    return ordered[max(1, math.ceil(0.75 * len(ordered))) - 1]


def judge(samples: dict[str, dict[str, list[float]]]) -> tuple[dict, bool]:
    """samples: {viewport: {metric: [values]}}; 空样本按失败处理。"""
    report, failed = {}, False
    for vp, metrics in samples.items():
        report[vp] = {}
        for metric, line in REGRESSION.items():
            values = metrics.get(metric) or []
            if len(values) < 20:
                report[vp][metric] = {"p75": None, "pass": False, "reason": "samples<20"}
                failed = True
                continue
            value = p75(values)
            ok = value <= line
            failed = failed or not ok
            report[vp][metric] = {
                "p75": value,
                "target": TARGET[metric],
                "regression": line,
                "pass": ok,
            }
    return report, failed


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("--samples", type=int, default=20)
    parser.add_argument("--out", type=Path, default=None)
    args = parser.parse_args()

    #       两档视口各 args.samples 次采样 → samples → judge → 证据 JSON

if __name__ == "__main__":
    raise SystemExit(main())
```
