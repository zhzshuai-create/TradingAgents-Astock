## 五、接口与口径

### 5.1 信封

- 字段：`schema_version` 固定 `"market-envelope-v1"`；`status` ∈ `ok|empty|error|stale`；`source`；`as_of`；`fetched_at`；`is_stale`；`stale_reason`；`error_code`；`error_message`；`partial`；`failed_blocks`；`data`。
- `empty`/`error`：`data=null`、`as_of=null`；`error` 必须有 `error_code`，`empty` 必须没有。
- `stale`：`data` 非空、`as_of` 非空、`stale_reason` 必填、`is_stale=true`。
- `ok`：`is_stale=false`、`stale_reason=null`。
- 多块接口必须给 `blocks`；合并规则按 `api-v1.md` 3.0 的五行表；`partial=true` 时 `failed_blocks` 非空。

### 5.2 来源与时间

- `source` 固定集合：`tencent`、`eastmoney`、`ths`、`hexin`、`cls`、`mootdx`、`mootdx-cache`、`baidu`、`mixed`、`static`。
- `fetched_at` 与 ISO 形态的 `as_of` 用 CST（`+08:00`）；`as_of` 也允许 `YYYY-MM-DD`。
- `market_session`：北京时间；工作日 `09:30–11:30`、`13:00–15:00` 为 `trading`，`11:30–13:00` 为 `lunch_break`，`09:30` 前 `pre_open`，其余 `closed`；周末 `closed`。节假日不引入日历表：指数日期早于今天时按 `trading_day_mismatch` 标 stale。

### 5.3 缓存

- 缓存键：`(endpoint_id, 规范化参数)`；值含数据、`as_of`、`fetched_at`、`source`、`status`、`error_code`、`stale_reason`。
- `stale_after` 直接取 `api-v1.md` 3.0 表，不另造数字。
- 命中且未过期 → `ok`；命中但超过 `stale_after` → 尝试刷新；刷新失败且旧数据存在 → `stale`（`ttl_exceeded` 或 `trading_day_mismatch`）；没有旧数据 → `error`。
- 同键并发只允许一个 provider 调用；其余等待同一结果。
- 备用源成功时按新鲜度给 `ok`/`stale`；`stale_reason=upstream_fallback`。

### 5.4 provider

- 默认实现可从 `tradingagents.dataflows.a_stock.{_common,signals,news,quote}` 复用纯函数；旧版写在 `web/data_functions.py` 的抓取（指数、行业、成分股、快讯、个股新闻、北向）必须重写到 backend，不能 `import web.*`。
- 四个数据源码：超时 `upstream_timeout`、限频 `upstream_rate_limited`、解析失败 `data_parse_error`、其它上游失败 `upstream_error`。
- 不调用会落盘的旧函数：`_load_ohlcv_astock`（写 CSV）、`_save_northbound_snapshot`、名称表重建、公告 PDF 缓存。
- 测试用 `FakeProviders` 注入，可配置延迟、异常、返回夹具。

## 十四、容易踩的坑

1. 旧 `_load_ohlcv_astock` 会写日 K CSV，`_save_northbound_snapshot` 会写 CSV；直接复用就违反零写盘。K 线与北向要么走只读分支，要么在 backend 重写。
2. 旧 `web/data_functions.py` 里的指数、行业、成分股、快讯、个股新闻、北向抓取不能 import；必须重写，且保留旧版 UA、限频与重试策略。
3. `market-data-envelope-v1.json` 对 `empty`/`error` 的 `as_of` 是 `null`，不是空字符串；`is_stale` 必须与 `status` 同步。
4. `partial` 不是第五态：顶层状态仍是 `ok`/`stale`，只是加 `partial=true` 与 `failed_blocks`。
5. 名称表不可用是 500 `internal_error`，不是 400；ticker 格式问题才是 400。
6. `TickerDirectory` 只读磁盘、不 `makedirs`；新 provider 也要遵守。
7. Windows 路径与 GBK 控制台；测试用 `tmp_path`，不要拼接真实 HOME。
8. 时间统一 CST；不要用本机裸 `datetime.now()` 判定 `market_session`。
