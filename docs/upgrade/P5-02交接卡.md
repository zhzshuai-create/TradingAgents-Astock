## 五、口径

### 5.1 刷新系数

```ts
const factor = refresh === "relaxed" ? 2 : 1;
const enabled = refresh !== "manual";
```

- `standard`：沿用 `REFRESH_INTERVALS` 原值（契约 `stale_after`），与现在完全一致。
- `relaxed`：间隔 ×2。指数 10s→20s，快讯 120s→240s，行业 300s→600s，行情 60s→120s，分时今日 30s→60s。
- `manual`：返回 `{ refetchInterval: false, refetchIntervalInBackground: false }`。
- 隐藏页下限不变：`Math.max(effective, HIDDEN_POLL_MS)`；隐藏页永不快于 60s。
- `usePolling(false)` 的既有语义保留：仍直接返回两个 false。
- `useVisibleRefetch`：手动档下 hidden→visible 不做 `invalidateQueries`；`refreshNow` 照常可用。
- 切换即时生效：`usePreferences` 触发重渲染后，查询观察者在新一轮渲染拿到新 `refetchInterval`，不重建 QueryClient。

### 5.2 导出入口

- `api/reports.ts` 新增：

```ts
export function reportMarkdownUrl(reportId: string): string {
  return `/api/v1/reports/${encodeURIComponent(reportId)}/markdown`;
}
```

- `ReportActions` 同时渲染 PDF 控件与 Markdown 链接，两处（`variant="header"` 与 `"bar"`）一致：

```tsx
<a
  href={reportMarkdownUrl(reportId)}
  download
  data-testid="export-markdown"
>
  下载 Markdown
</a>
```

- `export: "pdf"` 时 PDF 在前，`"markdown"` 时 Markdown 在前；两种格式始终可达，禁用一个不行。
- Markdown 链接不发 POST、不轮询、不新增接口；`fetch` 与 `/api/v1` 字面量仍只在 `frontend/src/api/`。
- `reportId` 从 `ReportReaderPage` 的 `meta.report_id` 传入；为空字符串时不渲染下载链接，不另发请求。
