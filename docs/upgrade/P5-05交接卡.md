## 五、口径

### 5.1 桌面侧栏入口（LEG-01）

- 位置：`SECONDARY_NAV.map` 之后，同一个 `<ul>` 里追加一个 `<li>`；不要放进 `SECONDARY_NAV`（那不是路由项，`isNavActive` 与 `pageTitle` 不适用）。
- 用原生 `<a href={LEGACY_ENTRY_URL}>`，**不要**用 `Link`/`NavLink`；`target="_blank"`、`rel="noreferrer"`。
- 结构照搬移动端：`<Icon name="external" />` + `<span className={styles.label}>旧版入口</span>`。
- 折叠态：与 `NavLink` 一致，`title={collapsed ? "旧版入口" : undefined}`；`aria-label` 不需要，文本始终在 DOM 里。
- 不复用 `styles.active`，外链没有当前页语义；`aria-current` 不设。
- 测试用 `within(screen.getByRole("complementary", { name: "主导航" }))` 或 `within` 侧栏定位；不要全局 `getByRole("link", { name: "旧版入口" })`，移动抽屉会重复。

### 5.2 设置关于入口（LEG-02）

- 在「关于」组现有 `dl` 里加一行：`<dt>旧版入口</dt>` + `<dd><a href={LEGACY_ENTRY_URL} target="_blank" rel="noreferrer">打开旧版界面<Icon name="external" /></a></dd>`；`data-testid="about-legacy-entry"`。
- 链接文字用「打开旧版界面」而非孤零零的「旧版入口」，读屏与 axe 链接名称更明确；不改其余行。
- 最后一段改为只讲许可：「第三方数据遵循各自授权，具体许可以各数据源发布的信息为准。」不得留下「后续票据」「补齐」「占位」等字样。
- 版本、构建说明、免责声明、四组顺序与 `#group-about` 深链全部不变。

### 5.3 外链不被 React Router 拦截（LEG-03）

- 两处都是原生 `<a>` + 绝对 URL；点击必须触发浏览器新窗口，SPA 的 `location.pathname` 不变。
- E2E：给 `http://localhost:8501/**` 加 `context.route` 桩，点击后 `page.expect_popup()` 捕获新页，断言 `popup.url` 以 `http://localhost:8501` 开头；原页 URL 仍是 `{base}/settings`。
- 移动端抽屉入口本票不重写，但要回归：属性一致、点开同样弹新页。
- 不写 8501 的前端路由；不把入口换成 `Link`。
