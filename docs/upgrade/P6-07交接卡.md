### 2.3 切默认（唯一需要你当场确认的一步）

口径先对齐（**开工时请确认**）：`.env.stack` 是唯一开关文件，仓库缺省仍是 legacy（`backend/app/core/write_mode.py` 的 `DEFAULT_WRITE_MODE`，api-v1 契约写明缺省按 legacy 理解）。所以「切默认」= 本机写 `ACTIVE_ANALYSIS_UI=next`，之后双击 `run_all.bat` 起的是新版。不把 `DEFAULT_WRITE_MODE` 改成 next —— 那会改冻结契约语义，超出本票边界。

- 顺序：八步演练通过 → 确认 8501 无监听 → `stack_mode.py set next --real-models?` → `run_all.bat`（或 `stack_launch.py`）起 8600 → 冒烟。

## 五、已知坑

1. **系统 Python 3.12 没有 streamlit**：预检冒烟与旧版启动都用 `.venv`；e2e 脚本用系统 3.13 + Playwright。
2. **旧版写真实家目录**：`legacy_projection.default_logs_root()` 恒写 `Path.home()/.tradingagents/logs`；只隔离 `TA_DATA_ROOT` 不够。
3. **桌面 `AStock-UI-dev.bat` 绕过 `.env.stack`**：它跑 `dev_backend.py` 并强制 next，还固定占 8600。开工前必须关掉，否则演练与 `set` 都会撞端口。
4. **`e2e_p5` 会改两份受控证据文件**：`restore_generated()` 已处理；e2e_p6 复用这个逻辑，别另写。
5. **预检要求工作区干净**：`e2e_p6` 末尾的预检要在「证据已提交或已在基线」的状态下跑；否则先提交再跑。
6. **P2–P4 默认各自构建**：调用时全部传 `--skip-build`，否则构建会跑四次。
7. **P4 会跑 Python 全量**：传 `--skip-python-full`，否则全量跑两次。
8. **切默认是进程启动值**：写完 `.env.stack` 必须重启后端；`status` 会报 mismatch 而不是假装一致。
9. **真实目录替换不在本票默认范围**：只做副本；真实替换需你逐次确认。
10. **不跑真实模型**：冒烟不建真实任务；`--real-models` 只是透传，仍要求 `TA_ENABLE_REAL_RUNNER=1`。
11. **迁移只验不降级**：`alembic heads` 单头 `0007`，`alembic_version=0007`；不执行 downgrade。
12. **Windows 控制台 GBK**：脚本入口已 `sys.stdout.reconfigure(encoding="utf-8")`；外部命令输出先剥 ANSI 再解析。
