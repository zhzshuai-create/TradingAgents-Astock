## 五、证据（必须原始输出，不接受转述）

数据库（`sqlite3 ~/.tradingagents/jobs.db`）：

```sql
SELECT id, status, error_code, error_message, report_id, started_at, finished_at
FROM jobs WHERE id = '<job_id>';
SELECT seq, payload FROM job_events
WHERE job_id = '<job_id>' AND type = 'stats' ORDER BY seq DESC LIMIT 1;
SELECT report_id, chart_snapshot_status, content_hash, rating, signal
FROM reports WHERE job_id = '<job_id>';
```

文件：

- `~/.tradingagents/job_reports/<job_id>/report.json`：sections 数量、正文长度、无 `U+FFFD` / `锟斤拷` / 控制字符。

- `docs/upgrade/reviews/2026-11-XX_P6-09S6收口.json`：job/meta/SQL/log/文件检查的原始输出。
- `docs/upgrade/reviews/2026-11-XX_P6-09S6收口评审.md`：结论、调用数与 token、耗时、失败就写 blocked 与供应商响应。

## 七、已知坑

1. **桌面 `AStock-UI-dev.bat` 是假执行器**：`dev_backend.py` 固定 FakeAnalysisExecutor，报告正文是「合成文本」；它占 8600/5173，不能作为 S6 证据，开工前必须关。
2. **预览绑定**：`stack_launch` 已给 `vite preview` 加 `--host 127.0.0.1`；直接手起 preview 会只监听 `[::1]:5173`。
3. **后端不下发 SPA**：`GET 8600/` 404 是设计，页面走 5173。
4. **dist 不入库**：缺 `frontend/dist/index.html` 时先 `npm run build`。
5. **`.env` 与 llm_config 不回显**：证据只写 provider / model / base_url；`TA_ENABLE_REAL_RUNNER=1` 只检查存在。
6. **GBK 控制台**：打印中文用 `PYTHONIOENCODING=utf-8`；读文件用 Read/Python，不用 `cat`。
7. **表结构**：任务主键是 `jobs.id`（没有 `job_id` 列）；stats 在 `job_events.payload`，不是 jobs 列。
8. **同配置活跃任务**：新幂等键在已有同股同日同配置进行中任务时返回 200 旧 job；换股票或等终态。
9. **余额/限流**：DeepSeek 返回 402 或 429 时停止，记 blocked 并附响应体；不要自动换模型重放。
10. **关栈**：只结束 `run_all.bat` 的进程树，别杀整个 Python；结束后逐端口复核。
