## 六、已知坑

1. **`start_journal()` 用调用方解释器**：`web/journal_service.py:47` 里是 `sys.executable`。`run_all.bat` 外层是系统 Python 3.12（没有 streamlit），所以 next 分支不能直接调 `start_journal()`，要用 `.venv/Scripts/python.exe -m streamlit` 显式起，或给 `start_journal` 传解释器（那会动 `web/`，本票边界内不推荐）。
2. **预览默认只绑 IPv6**：实测 `vite preview` 监听 `[::1]:5173`，`127.0.0.1:5173` 探活会拒绝。必须加 `--host 127.0.0.1`，否则 `status`、e2e 探活和浏览器地址三处口径不一致。
3. **后端不托管 SPA**：`GET /` 404 是设计，不是故障；冒烟必须走 5173。
4. **`dist` 不入库**：`frontend/dist/` 在 `.gitignore`，新克隆或清理后预览起不来；先 `npm run build`。
5. **日志探针永不自启**：meta 只报 `available/reason`，页面只给引导；要 8502 可用，必须本票真的拉起进程。
6. **`set` 重启后端会丢 `--real-models`**：切模式时如果后端在跑，要么带 `--real-models`，要么先停后端再 `set`。
7. **桌面 `AStock-UI-dev.bat` 不是日常入口**：它跑 `dev_backend.py`，数据根是临时目录、强制 next、还占 8600/5173。开着它时 `run_all.bat` 会被护栏拒绝；别为了让它跑而杀进程。
8. **端口清理**：Windows 下 `taskkill //PID` 要用双斜杠；只结束命令行里含 `run_backend.py` / `vite.js` / `trade-journal` 的本栈进程。
9. **真实任务要花钱**：S6 不做就如实记录「真实链路未验」，不能拿假图跑通冒充验收。
10. **`.env` 不回显**：只检查键是否存在；证据里不出现任何密钥或完整环境值。
