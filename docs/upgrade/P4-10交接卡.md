## 八、容易踩的坑

1. 这次新增了 `**/api/v1/stocks/**` 夹具到 market 与 shell 两套 E2E；任何新页面在旧套件里取数，都要先补契约内的桩，否则 preview 回 500，套件会把它算成控制台错误。
2. 新开股票路由后，`e2e/shell_e2e.py` 的深链断言读的是第一个 `h1`；空快照下 h1 是代码，不是名称，也不是旧占位标题。
3. 页签滚动记忆必须在换页前记录（`patch()` 里读 `scrollTop`）。effect 里读会被短页签的高度夹到 0；本次实测 127 丢失，修复后 127 恢复。
4. 启动器要按 `open` 条件挂载。常驻挂载时 `useState(initialTicker)` 在快照未到时固化 `name: null`，异步到达的名称永远不显示。
5. 同步 Playwright 里 `time.sleep()` 会阻塞事件回调；轮询请求列表要用 `page.wait_for_timeout(50)`，否则请求已发出仍判超时。
6. 未知 ticker 的 400、报告 500 会留下浏览器资源加载日志；错误态流程只断言无 JS 异常，正常流程仍要求控制台 0 错误。不要把两者混用。
7. 非法 `tab`/`period`/`date` 在加载时只回退渲染，URL 仍保留原始非法值；用户下一次交互才写规范化 query。E2E 不要断言加载后的 query 已被清理。
8. 新闻只把绝对 http(s) 变锚点；`javascript:` 与脚本标签必须是可见文本。不要为移动端改成 `dangerouslySetInnerHTML`。
9. 图表在移动端不接手势：K 线容器自身 `overflow-x:auto`，触控指针不进拖拽；P4-10 只加周期按钮与容器横滑，不加双指缩放。
10. 运行 `e2e/e2e_p3.py` 会改写 `reviews/2026-11-06_P3-09性能结果.json`，跑完必须 `git checkout --` 还原；`check_bundle.mjs` 用 `--out` 写临时文件，别覆盖 P4-04 证据。
11. 全量 vitest 并行下 AppShell 路由用例已把查询超时调到 4 s；不要为单次波动再调大。
12. 桌面视口 1440×900 下本票已确认页面可滚动、滚动记忆可测；移动端内容更短，W07M 的横滑与吸底条要用容器/元素几何断言，不要靠整页滚动。
