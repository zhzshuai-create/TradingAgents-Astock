## 五、口径

### 5.1 路由焦点（KB-01）

- 用 `useRef(true)` 标记首次渲染：挂载后的第一次 effect 只把标记置 false，不聚焦。
- `pathname` 变化时 `document.getElementById("main-content")?.focus({ preventScroll: true })`；`main` 已有 `tabIndex={-1}`，不需要额外 tabindex。
- 只依赖 `pathname`：`#group-model` 之类 hash 变化不触发聚焦，避免设置页深链把焦点从分组标题抢走。
- 不重置滚动位置（既有行为，不在本票）；不聚焦 `h1`（`main` 已能承接读屏上下文）。

### 5.2 标题（KB-02）

- `document.title = `${pageTitle(pathname)} · AStock Pro``；挂载时也设置一次，路由变化时更新。
- 不在页面组件里各写一份 `document.title`；只在 shell 一个地方。
- 未知路由返回 `pageTitle` 的默认「AStock Pro」，标题为「AStock Pro · AStock Pro」不可接受：未知路由直接写 `AStock Pro`，或在 `pageTitle` 返回默认值时只写一次产品名。
- 关闭标签/卸载不需要恢复旧标题。

### 5.3 跳过链接与导航顺序（KB-03/04）

- 跳过链接已是第一个可 Tab 元素（`AppShell.tsx:55`）；确认点 Enter 后焦点落到 `#main-content`。
- 桌面 Tab 顺序：跳过链接 → 品牌链接 → 主导航（工作台/市场/任务/报告）→ 次级（交易日志/设置/旧版入口）→ 收起侧栏 → 顶栏搜索与主题。
- 外链「旧版入口」是普通 `<a>`，Tab 可达；不要给它 `tabIndex=-1`。
- 所有焦点样式走既有 `:focus-visible` 令牌，不新增 `outline: none`。

### 5.4 搜索（KB-05）

- `/` 或顶栏搜索框可 Tab 到达；输入后 Enter 进入股票页；结果列表项必须是 `button`/`a`，不是 `div`。
- 移动端「打开搜索」按钮 `aria-expanded` 已存在；Escape 关闭搜索面板并把焦点还给打开按钮。

### 5.5 对话框与抽屉（KB-06/07）

- 复用 `useDialogFocus`：打开后焦点在 `[data-autofocus]` 或第一个可聚焦元素；Tab 从末尾回到首个，Shift+Tab 反向；Escape 关闭；关闭后焦点回到触发按钮。
- 移动端「更多」抽屉：同样断言；关闭后 `body` 与 `[data-scroll-lock]` 的 `overflow` 恢复原值。
- 若发现 `useDialogFocus` 在「无触发元素」或「焦点在已卸载节点」时会丢焦点，做最小修补并补用例；不重写整个实现。

### 5.6 无陷阱与可访问名称（KB-08)

- 全站不允许键盘陷阱：除模态外，Tab 可在页面内循环走完并离开。
- 每个图标按钮必须有可访问名称；审计方式：RTL 渲染关键路由后，收集 `button`/`a` 的 `accessibleName` 为空者；或 Playwright `get_by_role` 断言。
- 不用 `role="button"` 包装 `div` 来绕过；能换原生元素就换。
