## 五、口径

### 5.1 axe 来源与注入（D11）

- 首选 `cd frontend && npm install --save-dev --save-exact axe-core@4.10.3`（若已发布更新的 4.10.x，取当时最新并写进证据），提交 lockfile。
- 注入 `frontend/node_modules/axe-core/axe.min.js`：用 `page.add_script_tag(path=...)`；全程离线，不使用 CDN。
- 只有 npm 不可用时，才把带 Apache-2.0 许可证头的 `axe.min.js` 放进 `e2e/vendor/`，并在证据里写版本与 sha256。
- 断言 `frontend/src` 无 `axe` 引用；`check_bundle` 入口与 P5-07 持平（允许 ±0.1 kB 的测量抖动）。

### 5.2 页面矩阵与夹具

- 九页：`/workbench`、`/market`、`/stocks/600519`、`/jobs`、`/jobs/job-1`、`/reports`、`/reports/r-long`、`/journal`、`/settings`。
- 宽度：1440×900 与 390×844 全跑；`/workbench`、`/market`、`/stocks/600519`、`/journal`、`/settings` 加 360×640。
- 报告阅读器夹具要含 Markdown 表格，让表头规则真正跑到；`/journal` 的不可用态与待机态各扫一次。
- 每页等 `[data-testid=page-*]` 与 `h1` 出现后再注入，避免把骨架当成页面而漏报。

### 5.3 级别与退出码

- 只统计 `wcag2a`、`wcag2aa`、`wcag21aa`、`wcag22aa` 标签。
- critical 与 serious 必须为 0；moderate/minor 记录规则名、影响级别、节点数与样例选择器，不阻断。
- 失败时非零退出，打印第一条违规的 `helpUrl` 与 3 个节点样例。
- 已知例外写进 JSON 的 `exceptions`，逐条带证据与理由；禁止用 `rules: { "x": { enabled: false } }` 关规则。

### 5.4 移动量测

- 每页 `document.documentElement.scrollWidth <= clientWidth`，不靠 `body` 的 `overflow-x: hidden` 兜底。
- 触控目标：可见 `button`、`a[href]`、`input`、`select`、`[role=button]` 的 `getBoundingClientRect()` 短边 ≥44（手机宽度下）；内联正文链接如不达标，逐条进豁免清单并写明理由。
- 设置页专项：四组的展开/收起、保存按钮、恢复默认按钮。
- 日志页专项：不可用、待机、运行中三态在 360 的换行与入口按钮。
- 截图 `ui_shots_p5/P5-08/{width}-{page}.png`，`ui_shots_*/` 已在 `.gitignore:229`，不入库。

### 5.5 修复边界

- `color-contrast` 违规只改 `frontend/src/styles/tokens.css`，不在组件里写死颜色。
- `aria-*` 修正只加属性，不改可见文案与布局。
- 修复后重跑全量单测与既有五套 E2E，断言数字不倒退。
- P5-07 记录的两条非文本对比（控件边框、禁用文字）不因 axe 未报就修改，保持记录。

### 5.6 证据

- 单行 JSON 输出到 stdout，同时写 `docs/upgrade/reviews/2026-11-XX_P5-08可访问性与移动结果.json`。
- 记录 axe 版本、注入路径、每页每宽度的 critical/serious/moderate/minor 数量与规则名。
- 记录 `check_bundle` 的入口与最大路由块；截图只写文件名，不写绝对路径。
