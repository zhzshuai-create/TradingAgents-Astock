## 三、P2-01/02 的取舍与遗留

- 组件只用语义令牌，基础色阶只在 `tokens.css` 内部互相引用；WEB-01 的十六进制扫描覆盖 `src` 下 `.ts/.tsx/.css`。
- Dialog/Drawer 用自建焦点陷阱，不依赖原生 `<dialog>`：jsdom 对 `showModal` 的支持不可靠，E2E 前也无法保证焦点语义。
- 开发入口把 uvicorn 放在线程、由主线程安装信号处理。原因：uvicorn 的 `capture_signals` 会在优雅退出后重发 SIGINT/SIGBREAK，若让 uvicorn 占主线程，进程退出码和租约释放都不受控；DEV-01/DEV-03 依赖退出码 0 与租约即时释放。
- Worker 拿不到全局租约时每秒重试，崩溃重启不必等人工；启动对账仍只在首次拿到租约后跑一次。
- 未做（按票交给后续）：服务状态真实值（P2-04）、全局搜索与活动任务条（P2-06）、按名称搜索（P2-03）。
- P2-02 的主题切换已完成并写 `localStorage`；顶栏与移动「更多」抽屉都有入口，`data-theme` 落在 `<html>`。
- E2E 用独立脚本 `e2e/shell_e2e.py`，不用 pytest：`.venv` 没有 Playwright，系统 Python 3.13 有。脚本自己构建、起 `vite preview`、结束后必须等到抽屉动效再截图，否则会截到滑入中间帧。
- jsdom 不为 `display:none` 的元素计算可访问名，底栏角色查询会在名称过滤上失败。WEB-03 用 `data-testid="mobile-nav"` 定位底栏，再按文本取链接与「更多」按钮。
- 移动端 44px 只加在 `@media (max-width: 767px)` 的 Button 上，桌面按钮仍保持 34px 密度；搜索提交按钮单独设最小高度。
- P2-02 的视觉走查已用 1440/390/360 截图完成，截图在 `ui_shots_p2/P2-02/`（`ui_shots_*/` 不入库）。
