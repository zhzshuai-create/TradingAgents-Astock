## 五、口径

### 5.1 分组与深链

```ts
export const SETTINGS_GROUPS = ["basic", "model", "data", "about"] as const;
export type SettingsGroup = (typeof SETTINGS_GROUPS)[number];
```

- 分组 id 固定为 `group-basic` / `group-model` / `group-data` / `group-about`，标题固定为「基本」「模型」「数据源」「关于」。
- 桌面 1440：四组同页依次排列，每组一个 `section[aria-labelledby]` 与 `h2 id="group-xxx"`。进入页面或 hash 变化时滚动到目标组；非法 hash 停在顶部，不报错、不写 fallback 值。
- 移动 390/360：先渲染四行分组列表；点一行把 `#group-xxx` 写入 URL 并进入该组二级页；二级页返回按钮清掉 hash 回到列表；刷新时按 hash 直接恢复到该组二级页；非法 hash 停在列表。
- 不新增路由，`routes.tsx` 的 `/settings` 懒加载不动。
- 深链用 React Router 的 `useLocation().hash` / `useNavigate()`，不用 `window.location.hash` 直接赋值。

### 5.2 本地偏好控件

| 控件 | 读取 | 写入 |
| --- | --- | --- |
| 密度（标准 / 紧凑） | `preferences.density` | `setPreferences({ density })` |
| 刷新（标准 / 省流 / 手动） | `preferences.refresh` | `setPreferences({ refresh })` |
| 导出（PDF 优先 / Markdown 优先） | `preferences.export` | `setPreferences({ export })` |
| 默认模型 | `preferences.launcher.llm_profile` | `setPreferences({ launcher: { llm_profile: id } })` |
| 默认并行分析师 | `preferences.launcher.parallel_analysts ?? false` | `setPreferences({ launcher: { parallel_analysts: checked } })` |

- 修改即保存，不发请求，不调用后端；`usePreferences()` 的订阅会把新值同步到全站。
- 每次保存后 `aria-live="polite"` 区域显示「已保存」；页面重进后控件读回已存值。
- 默认模型下拉的选项只来自 `meta.llm_profiles` 的 `{ id, label }`；已存的 `llm_profile` 不在列表时显示「跟随服务端默认」，不自动清空存储。
- 并行分析师旁写实验性说明，不承诺结果。

### 5.3 只读信息与禁止项

- 基本：`metaOptionsQuery` 成功/失败状态、`app_version`、`contract_version`、`server_time`（保留原偏移，展示里必须能看到 `+08:00`）、SSE 最近一次连接结果、日志状态与 `/journal` 链接。Worker 状态不伪造，只给「以任务页活动任务为准」的入口。
- 模型：`llm_profiles` 的 id 与 label 只读列表；Base URL 与 API Key 只写「由服务端环境配置」，**不提供输入**。
- 数据源：刷新偏好、导出偏好、`journal.entry_url` 只读展示；行情数据源与最近成功时间不在此页另造状态，给 `/market` 链接。
- 关于：版本与构建说明；许可与免责声明文案；旧版入口留给 P5-05 补。
- 数据目录只写「由服务端本地管理」，不显示绝对路径。
- 硬断言一：页面无 `type="password"`，无 `api_key` / `base_url` 输入，DOM 与 localStorage 不出现密钥模式（`sk-`、`api_key`、`authorization`）。
- 硬断言二：设置页不发任何写请求；已有任务详情仍显示创建时快照，偏好修改只影响新任务启动器的默认值。

### 5.4 SSE 最近结果（C8）

在 `api/sse.ts` 增加模块级只读状态：

```ts
export type SseLastResult = "none" | "success" | "failure";
export function readLastSseResult(): SseLastResult;
export function subscribeLastSseResult(listener: () => void): () => void;
```

- `streamJobEvents` 握手成功（`onOpen` 被调用）时记 `success`；握手、HTTP、协议或网络失败时记 `failure`；`AbortError` 不改变记录。
- 只存内存，不写存储、不发请求；不代表 Worker 健康。
- 页面文案固定：`none` →「未连接」；`success` →「最近一次连接成功」；`failure` →「最近一次连接失败」。
