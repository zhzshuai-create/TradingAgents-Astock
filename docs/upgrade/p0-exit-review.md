3. 用假图跑一次 P1-01 的空库迁移演练，确认旧版 Streamlit 不受影响。

### 2.7 真实模型默认禁用

GF-05 断言假图默认路径不访问网络、不创建模型客户端、不写真实报告目录。

假图模块不导入任何模型 SDK。P1 的执行器工厂默认返回假图，真实执行器需要环境变量与配置双条件才开启（AD-01）。

P1 的 42 个用例与 28 个 GF 用例全部指定假图或打桩执行器。测试不读取 API Key。

旧版 Streamlit 保留原有模型调用能力，这是旧版行为，本阶段未改；新内核默认不启用真实模型。

## 6. 冻结后的变更规则

冻结不意味着永远不能改。规则写在 `contracts/FREEZE-v1.md` 第 1 节与第 4 节。

新增可选字段、新增错误码、补文档与补测试不升版本。修改字段含义、状态转换、报告章节、SSE 规则或错误码动作要升到 v1.1。删除字段、状态、事件、错误码或替换黄金样本要先评审。

任何冻结文件变化，必须在同一次提交更新冻结清单哈希，并在评审记录写清原因。先改代码再补契约不允许，只改契约不改测试也不允许。
