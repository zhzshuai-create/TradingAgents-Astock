## 六、容易踩的坑

1. 测试必须用临时 DB（`TA_JOBS_DB`）与临时报告目录（`TA_JOB_REPORTS_DIR`），不要污染 `~/.tradingagents`。
2. 事件与时间戳：任务/事件用秒，租约用毫秒；周期测量用 `time.monotonic`，不要用业务时钟。
3. SSE 测试必须显式带 `Accept: text/event-stream`，TestClient 默认 `*/*` 会被 400。
4. 审计事件（`created` / `transition_rejected` / `reconcile_note`）`seq` 为 NULL，不占事件流序号，不要把它们算进 1..1000。
5. 并发测试里「Worker 忙」必须真拿租约并挂 running 任务，不能只改状态。
6. 拒绝用单次样本代替五次中位数；拒绝在 `notes` 写「感觉更快」。
7. 测量结果要附环境信息（Python、OS、commit），`commit` 用 `git rev-parse --short HEAD` 的实际值。
