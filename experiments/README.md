# 实验设施

本目录提供两类可复现实验脚本与论文基准实验的原始结果数据。

- `run_analysis_once.py` — **T1 性能实验**：单次完整分析（串行 vs 并行），记录墙钟时间、LLM 调用数、token 用量、最终信号，结果带时间戳落盘且绝不覆盖。
- `backtest_eval.py` — **T2 回测实验**：对信号日产生的分析信号做方向命中统计（信号日收盘 → 评估日收盘），纯数据计算，零 LLM 成本。

两条铁律（脚本内置）：

1. 对项目仓库**只读**——运行前后各做一次 git HEAD + 工作区状态校验，任何变更立即报错；
2. 结果文件带时间戳命名、绝不覆盖，并追加登记到 `results/manifest.csv`。

## 用法

```bash
# T1：串行 / 并行各跑一次同一标的同一交易日
python experiments/run_analysis_once.py --ticker 000858 --date 2026-09-11 --mode serial
python experiments/run_analysis_once.py --ticker 000858 --date 2026-09-11 --mode parallel

# T2：对信号日 2026-08-13 的信号做方向命中统计（评估日 2026-09-11）
python experiments/backtest_eval.py
```

模型配置从仓库根目录 `.env` 读取（`LLM_PROVIDER` / `DEEP_THINK_LLM` / `QUICK_THINK_LLM` / `BACKEND_URL`），与 Web UI 同一套配置入口。

## 基准实验结果（2026-09-13，results/ 为原始数据）

环境：小米 MiMo `mimo-v2.5`（OpenAI 兼容协议直连），7 分析师完整 pipeline。

### T1 并行加速（串行 → fan-out 并行）

| 标的 | 串行 | 并行 | 降幅 | 结果文件（results/） |
|------|------|------|------|----------------------|
| 000858 五粮液 | 694.4s | 559.3s | -19.5% | `run_20260913-033457_*` / `run_20260913-034444_*` |
| 601318 中国平安 | 684.3s | 508.2s | -25.7% | `run_20260913-063048_*` / `run_20260913-063944_*` |
| 300750 宁德时代 | 8001.7s* | 466.7s | -94.2% | `run_20260913-061035_*` / `run_20260913-061900_*` |

\* 300750 串行 8002s 为供应商侧延迟方差异常值（LLM 服务商当日抖动），同一配置其余串行运行约 690s；并行模式 467s 恰好体现 fan-out 对单点延迟的天然免疫——最慢的分析师不再拖累整体。

### T2 方向性命中（信号日 2026-08-13 → 评估日 2026-09-11，约一个月）

| 指标 | 值 |
|------|-----|
| 样本 | 6 只（000001 / 000333 / 002594 / 600036 / 600519 / 601899） |
| 方向性信号 | 2 条（000001 Overweight、601899 Overweight） |
| 命中 | 2 / 2 = **100%** |
| 中性信号 | 4 条 Hold（不参与方向命中，体现系统偏保守） |

原始数据：`results/backtest_eval_20260913-073957.json` 及各 `run_*.json`。

> ⚠️ 样本量小（6 只 / 1 个月），统计意义有限，仅用于验证系统能产出可回溯、可评估的方向性输出，不构成投资建议。
